Git version control project

In this table I listed a group of words fetched from API. These are coloured following the next conditions listed below based on the length of the specific word.

  • Longest words: red colouring
  • Shorter than 5 characters: blue colouring

Notice that the longest words' group can be manipulated by adding a 2 character longer word than the actual longest one. The red colouring goes only on the new inserted word.

You can save words to local storage by clicking on the button next to the words. If you would like to insert new words on the list, you can write and submit it in the input field.
