API Words

Git version control project

In this table i listed a group of words fetched from API. These are coloured following the next conditions based on the length of the specific word. Conditions are listed below.

  • Longest words: red
  • Shorter than 5 character: blue

Notice that the longest words' group can be manipulated by adding a 2 character longer word than the actual longest one. The blue colouring goes only on the new inserted word.

You can save words to local storage by click the button next to the words. If you would like to insert new words on the list, you can write and submit it in the input field.
